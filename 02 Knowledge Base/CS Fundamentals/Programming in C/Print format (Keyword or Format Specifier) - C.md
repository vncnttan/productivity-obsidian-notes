`printf("%d", variable_name);`
Used by print to print variables, the placeholder are:
- `%c` (char)
- `%d` (digit)
- `%i` (int)
- `%f` (float)
- %s (string)


Modifying format specifier
- `%lf / %ld` for long float/double
- `%.2f` to format how much decimal places behind comma you want to print
